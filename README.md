# news-image-20261121

Sum up 21 November 2026's world news in one image — entry for make.fun's daily news image bounty.

## Run

```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `entry.png` (a 1024×1024 newspaper-style collage of the day's top stories) to `/output/entry.png`.
